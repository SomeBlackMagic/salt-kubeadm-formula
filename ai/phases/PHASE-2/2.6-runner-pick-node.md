# Phase 2.6 — Runners `pick_init_node` и `pick_source`

## Цель

Read-only runners для выбора узлов: init node для bootstrap, source node для cluster-level операций.

## Файлы

- `_runners/kubeadm.py` — `pick_init_node`, `pick_source`, `_check_master_health`, `_nodegroup_members`
- `test/unit/test_runner_kubeadm.py::TestPickSource`

## Зависимости

- Phase 2.4 (transport layer)

## Scope

### `pick_init_node(nodegroup, source_ip, transport)`
- `source_ip` задан → возвращает его
- Иначе первый хост из nodegroup
- Пустой nodegroup → RuntimeError

### `pick_source(nodegroup, transport, source_ip)`
- Первый master, который: `/readyz` OK, etcd healthy, node Ready, `admin.conf` существует
- `source_ip` задан → проверяет только его
- Нет healthy master → RuntimeError

### `_check_master_health(node, transport)`
- `admin.conf` существует
- `/readyz` OK через remote http.query
- etcd `/health` OK
- `kubectl get node` → condition Ready=True

### `_nodegroup_members(nodegroup, transport)`
- `test.ping` по nodegroup → sorted list of responding minions

## Тесты
