# Phase 2.9 — Orchestrate `orch/kubeadm/bootstrap.sls`

## Цель

Orchestration state для создания single-master кластера. Связывает все компоненты Phase 2 в единый flow.

## Файлы

- `orch/kubeadm/bootstrap.sls`
- `test/unit/test_orch_bootstrap_render.py`

## Зависимости

- Phase 2.5 (`cluster_exists`, `endpoint_precheck`)
- Phase 2.6 (`pick_init_node`)
- Phase 2.7 (`kubeadm/init_cluster.sls`)

## Scope

### Порядок шагов

1. **Guard** — `kubeadm.cluster_exists` → True = fail (кластер уже есть)
2. **Endpoint precheck** — `kubeadm.endpoint_precheck` (DNS + TCP)
3. **Pick init node** — Jinja: `pick_init_node(nodegroup, source_ip)`
4. **Containerd** — `salt.state` → `containerd` на init node
5. **Node states** — `salt.state` → `kubeadm` (binaries, kubelet, config)
6. **Preflight** — `salt.state` → `kubeadm.init_cluster` с `_phase: preflight`
7. **Init** — `salt.state` → `kubeadm.init_cluster` с `_phase: init`
8. **Health check** — `salt.state` → `kubeadm.init_cluster` с `_phase: health`
9. **Event** — `event.send` → `kubeadm/bootstrap/done/<node>`

### Transport-agnostic

```jinja
{%- set transport = salt['pillar.get']('kubeadm:orchestrate:transport', 'minion') %}
{%- set ssh_kwarg = 'ssh: True' if transport == 'ssh' else '' %}
```

Каждый `salt.state` шаг передаёт `test: {{ opts['test'] }}` явно.
