# Phase 2.2 — State `kubeadm.healthy`

## Цель

State функция для проверки здоровья control plane после инициализации.

## Файлы

- `_states/kubeadm.py` — функция `healthy`
- `test/unit/test_state_kubeadm.py::TestKubeadmHealthy`

## Scope

- Health checks: `/readyz` (apiserver), `/health` (etcd), kubelet
- `http.query` для HTTP-проверок — **не cmd.run для curl**
- `service.status` для kubelet — **не cmd.run**
- Retry логика: `retries` попыток с `interval` секунд между ними
- `test=True`: одна проверка без retry, `result: None`

## Тесты

1. `test_all_checks_pass` — все проверки OK → result=True
2. `test_readyz_fails` — apiserver /readyz fail → result=False
3. `test_test_mode_single_check` — test=True → одна проверка, нет retry
4. `test_kubelet_check_uses_service_status` — kubelet через service.status
