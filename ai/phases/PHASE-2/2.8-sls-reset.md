# Phase 2.8 — SLS `kubeadm/reset.sls`

## Цель

State файл для полного сброса kubeadm на узле. Требует явного подтверждения через pillar.

## Файлы

- `kubeadm/reset.sls`
- `test/unit/test_reset_render.py`

## Зависимости

Нет (независимый от остальных подфаз).

## Scope

### С `confirm_reset: true`
- `kubeadm reset -f` (через `cmd.run`, onlyif admin.conf или kubelet.conf)
- Cleanup директорий: `/etc/kubernetes`, `/var/lib/etcd`, `/etc/cni/net.d`
- iptables flush через `module.run`
- Порядок: reset → cleanup → iptables (require chain)

### Без `confirm_reset`
- `test.fail_without_changes` с сообщением о необходимости confirm

## Тесты

1. `test_refuses_without_confirm` — без confirm_reset → fail_without_changes
2. `test_runs_with_confirm` — confirm_reset: true → выполняет reset + cleanup
