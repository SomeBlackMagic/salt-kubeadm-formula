# Phase 2.4 — Runner transport layer

## Цель

Унифицированный transport layer для вызова функций на узлах через minion или salt-ssh.

## Файлы

- `_runners/kubeadm.py` — `_client`, `_cmd`, `_endpoint_url`, `_http_check`, `_truthy_result`
- `test/unit/test_runner_kubeadm.py` (базовые тесты)

## Scope

- `_client(transport)` — возвращает `LocalClient` (minion) или `SSHClient` (ssh)
- `_cmd(target, fun, arg, kwarg, transport, tgt_type)` — унифицированный вызов
- `_endpoint_url(endpoint, path)` — построение URL из controlPlaneEndpoint
- `_http_check(url, timeout)` — проверка HTTP endpoint (SSL unverified)
- `_truthy_result(result)` — извлечение boolean из dict-результата cmd
- Валидация unknown transport → `ValueError`

## Тесты

1. `_client("minion")` → LocalClient
2. `_client("ssh")` → SSHClient
3. `_client("unknown")` → ValueError
4. `_http_check` с различными ответами
