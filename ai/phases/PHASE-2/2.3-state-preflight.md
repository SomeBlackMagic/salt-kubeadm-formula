# Phase 2.3 — State `kubeadm.preflight`

## Цель

State функция для preflight-проверок и pre-pull images перед init.

## Файлы

- `_states/kubeadm.py` — функция `preflight`
- `test/unit/test_state_kubeadm.py` (тесты preflight)

## Scope

- `kubeadm init phase preflight --config ...`
- `kubeadm config images pull --config ...` (опционально, `pull_images=True`)
- `--ignore-preflight-errors` опционально
- `test=True`: возвращает `result: None`, описание что будет сделано
- Ошибка → `result: False` с описанием

## Тесты

1. test=True не запускает команды
2. Успешный preflight → result=True, changes содержит выполненные команды
3. Ошибка preflight → result=False
