# Phase 2.5 — Runner `cluster_exists`

## Цель

Read-only runner для определения существует ли кластер. Используется как guard в orchestrate.

## Файлы

- `_runners/kubeadm.py` — `cluster_exists`, `endpoint_precheck`
- `test/unit/test_runner_kubeadm.py::TestClusterExists`

## Зависимости

- Phase 2.4 (transport layer)

## Scope

### `cluster_exists(nodegroup, transport)`
- Проверяет `/readyz` через controlPlaneEndpoint (HTTP)
- Проверяет `admin.conf` на каждом master через nodegroup
- Проверяет `etcd.yaml` manifest на каждом master
- Двухканальная проверка: LB может быть down, но кластер существует
- Возвращает `True` если хотя бы один признак найден

### `endpoint_precheck(endpoint, timeout)`
- DNS resolve controlPlaneEndpoint
- TCP connect на порт (default 6443)
- Ошибка → RuntimeError с описанием

## Тесты

1. `test_no_cluster` — ни одного признака → False
2. `test_cluster_via_readyz` — /readyz 200 → True
3. `test_cluster_via_admin_conf` — admin.conf есть (LB down) → True
