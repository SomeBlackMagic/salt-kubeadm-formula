# Phase 2.1 — State `kubeadm.initialized`

## Цель

State функция для инициализации первого master-узла через `kubeadm init`.

## Файлы

- `_states/kubeadm.py` — функция `initialized`
- `test/unit/test_state_kubeadm.py::TestKubeadmInitialized`

## Scope

- Guard: если `/etc/kubernetes/admin.conf` существует — no changes
- Запуск `kubeadm init --config ... --upload-certs`
- `--skip-phases` для `managed_by: external` (kube-proxy, coredns)
- `--ignore-preflight-errors` опционально
- `test=True`: возвращает `result: None`, рендеренный конфиг, не запускает init
- Ошибка `cmd.run_all` → `result: False`
- **НЕ cmd.run**: custom state вызывает `cmd.run_all` с `python_shell=False`

## Тесты

1. `test_already_initialized_no_changes` — admin.conf есть → no changes
2. `test_init_runs_kubeadm` — admin.conf нет → запускает init с правильными аргументами
3. `test_init_test_mode_no_changes` — test=True → result=None, cmd.run_all не вызван
4. `test_init_failure_returns_false` — retcode=1 → result=False
5. `test_skip_phases_external_proxy` — skip_phases → `--skip-phases=addon/kube-proxy`
